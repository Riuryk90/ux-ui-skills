# Release Notes - UX/UI Skills 1.0.0

This public package prepares the UX/UI Skills project for GitHub distribution without changing the validated behavioral corpus.

## Included Skills

- `ux-ui-build`: design, build, improve, and implement UI/UX work when authorized.
- `ux-ui-review`: read-only heuristic UX/UI review with severity, confidence, evidence discipline, accessibility signals, ethical-UX signals, and clear boundaries.
